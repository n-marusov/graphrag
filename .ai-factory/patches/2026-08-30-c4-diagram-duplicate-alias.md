# Дубликат алиаса store в C4-диаграмме container.md скрывал ContainerDb

**Date:** 2026-08-30
**Files:** specs/c4/container.md, specs/c4/context.md
**Severity:** medium (контейнер уровня 2 отсутствовал на диаграмме)

## Problem

`ContainerDb(store, "Хранилище графа и векторного индекса", ...)` не отображался на диаграмме контейнеров: на рендере был виден только внешний `System_Ext(store, "Внешнее хранилище документов (S3)", ...)`. Внутреннее хранилище (граф + векторный индекс) отсутствовало на диаграмме, хотя в таблицах документа описано корректно. Пользователь заметил пропажу при просмотре диаграммы.

## Root Cause

В Mermaid C4 алиасы узлов (первый аргумент макроса) должны быть **уникальны в пределах диаграммы**. В `container.md` алиас `store` был присвоен двум узлам: внутреннему `ContainerDb(store, ...)` и внешнему `System_Ext(store, ...)`. Mermaid при дубликате ID переопределяет узел последним определением — `System_Ext` затирала `ContainerDb`, поэтому внутреннее хранилище не рендерилось. Ошибка не ловилась при ревью: алиасы выбирались «по смыслу» (store = хранилище), диаграмма не рендерилась и не проверялась программно, а в markdown-исходнике дубликат не бросается в глаза.

## Solution

1. Внутреннее хранилище переименовано в `ContainerDb(graphstore, ...)`; внешний S3 остался `System_Ext(store, ...)` — алиасы стали уникальными.
2. Обновлена единственная ссылка на внутренний алиас: `Rel(core, graphstore, "Чтение и запись", "Bolt")`.
3. Сопутствующе (по запросу пользователя): подписи диаграммы сокращены до необходимого, добавлен `$c4ShapePadding="5"` для более квадратной формы блоков; аналогичная компактификация применена к `context.md`.

## Prevention

- При правке C4/mermaid-диаграмм проверять уникальность алиасов узлов в пределах **одной** диаграммы: ни один алиас не должен встречаться в двух макросах (`Person`/`System`/`System_Ext`/`Container`/`ContainerDb`/...).
- Использовать префиксы для «конфликтных по смыслу» сущностей: внутреннее хранилище — `graphstore`, внешнее — `store`; внутренние компоненты — `graph-*`, внешние — по имени системы.
- Быстрая проверка (пустой вывод = ок):
  `for f in specs/c4/*.md; do grep -hoE '\b(Person|System|System_Ext|Container|ContainerDb|Enterprise_Boundary|System_Boundary|Boundary)\([a-zA-Z0-9_]+' "$f" | sed 's/.*(//' | sort | uniq -d; done`
- При ревью диаграмм рендерить их или прогонять проверку алиасов — визуальные баги Mermaid (дубликаты ID, неподдерживаемые макросы) в исходнике markdown не видны.
