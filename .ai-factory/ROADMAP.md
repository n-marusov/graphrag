# Project Roadmap

> GraphRAG — корпоративный evidence-based context layer и context compiler для ИИ-агентов: проверяемые ответы и компактный контекст со ссылками на источники и provenance.

## Milestones

- [x] **Зафиксировать vision, единый язык и целевую архитектуру** — подготовлены `specs/vision.md`, `specs/glossary.md`, ADR, C4-диаграммы, доменная модель, требования и QA-гейты.
- [x] **Собрать тонкий веб-интерфейс F1** — реализован Vue 3/Vite/Tailwind SPA-каркас чат-интерфейса с domain/application/adapters/ui/app слоями и API-адаптерами.
- [ ] **Зафиксировать реализационные контракты MVP** — оформить OpenAPI/MCP/внутренние контракты для F1–F4, связать их с FR/US/BR/NFR и эталонными кейсами K1, K4, K5, K17.
- [ ] **Поднять серверный Go-модуль и каркас контейнеров C4** — создать `src/backend/` как единый Go-модуль с точками входа `cmd/` и внутренними пакетами для API Gateway, Query Engine, Core, Indexing, MCP, Integrations, Monitoring.
- [ ] **Реализовать хранение графа, чанков, векторов и версий в Neo4j** — предоставить интерфейс хранилища, схему графа, версионные снапшоты и атомарную публикацию read-модели.
- [ ] **Реализовать F2: индексацию GitLab-корпуса** — автоматически обрабатывать markdown-спеки, код, онтологии и структурированные данные из GitLab через MR/webhook/сверку.
- [ ] **Реализовать F2: глобальный слой книг и legacy из S3** — индексировать PDF-документы через RAPTOR/StructRAG в отдельный граф с ассоциацией проектных сущностей.
- [ ] **Реализовать F1: проверяемые ответы** — выполнять retrieval/generation для конкретных и базовых обзорных вопросов с grounding, provenance, ссылками на артефакты и версией индекса.
- [ ] **Реализовать F3: анализ влияния и компиляцию контекста** — вычислять затронутые артефакты и собирать минимальный JSON-контекст для задач автоматической разработки.
- [ ] **Реализовать F4: MCP-доступ для ИИ-агентов** — предоставить инструменты `answer` и `compile_context` через MCP с Agent Gateway, квотами, бюджетом, планированием и аудитом.
- [ ] **Интегрировать контролируемый LLM-контур** — подключить локальные GPU/open-weight модели или корпоративный шлюз с фильтрацией утечек, аудитом и минимизацией LLM-вызовов.
- [ ] **Собрать Docker Compose контур MVP** — развернуть Go-сервисы, Neo4j, web static server, мониторинг и необходимые зависимости в однохостовом защищённом контуре.
- [ ] **Провести beta-стабилизацию качества** — измерить baseline метрик, достичь порога точности RAG ≥ 70%, стабилизировать извлечение сущностей и снизить галлюцинации.
- [ ] **Расширить контур качества и масштаба** — довести обзорные вопросы, QA-контексты, сверку поставки со спецификациями и оптимизацию retrieval для большего корпуса до уровня Фазы 2.
- [ ] **Развить экспертную систему** — добавить advanced GraphRAG, real-time обновление графа, автоматическое поддержание модели предметной области и полноценный onboarding-сценарий.
- [ ] **Интегрировать GraphRAG в процесс автоматизации разработки** — сделать трассируемость от требования до результата и постановку задач с полным контекстом стандартом процесса.
