# src — исходный код GraphRAG

Каталог продуктивной кодовой базы **GraphRAG** — корпоративной системы знаний на базе
ontology-grounded GraphRAG: индексация корпуса в граф знаний, онтологический слой,
ответы с привязкой к источнику, трассируемость, context compiler (MCP) для ИИ-агентов.

## Назначение папки

Здесь размещается весь код продукта: ядро, оркестрация пайплайнов, query engine,
MCP-сервер, интеграции и CPU-компоненты. Модули соответствуют функциям продукта
F1–F7 из [`specs/vision.md`](../specs/vision.md):

| Функция | Область |
|---|---|
| F1 | Индексация корпуса и граф знаний |
| F2 | Онтологический слой (DDD-модель) |
| F3 | Ответы с привязкой к источнику (grounding) |
| F4 | Трассируемость и анализ влияния |
| F5 | Накопление знаний и петля обучения |
| F6 | Context compiler (MCP) |
| F7 | Безопасный контур LLM |

## Ключевые правила для ИИ-агентов

| Правило | Описание |
|---|---|
| **Единый язык — Go** | Вся кодовая база пишется на Go ([ADR-IMPL.STACK.go-single-language-adoption](../specs/adr/ADR-IMPL.STACK.go-single-language-adoption.md)). Python и Rust исключены; нативный код — только через CGo к зрелым C-библиотекам и по измеримому критерию (профилирование/бенчмарк). |
| **Спецификации — источник правды** | Scope, границы и архитектурные решения — в [`specs/`](../specs/) (`vision.md`, `glossary.md`, `adr/`). Код не должен противоречить принятым ADR и вижну. |
| **Агент готовит — человек подтверждает** | Код, сгенерированный ИИ, проходит подтверждение человеком: контрактные тесты, ревью. |
| **Контрактные тесты до реализации** | Эталонные кейсы (K1, K4, K5, K17) фиксируются контрактными тестами до реализации метода. |
| **Минимизация контекста и LLM-вызовов** | Целевой контур — локальные GPU и open-weight модели с ограниченным контекстом; минимизация токенов — сквозное требование (онтологический слой, PathRAG, PPR). |
| **Безопасность периметра** | Данные разработки не покидают периметр; LLM исполняется только в контролируемом контуре с фильтрацией и аудитом. |
