# US-answers.grounding.cited-answer — Ответ на конкретный вопрос со ссылками на артефакты

```gherkin
@US-answers.grounding.cited-answer @UC-answers.grounding.cited-answer @P0 @answers @accessibility
Feature: US-answers.grounding.cited-answer Ответ на конкретный вопрос со ссылками на артефакты (K1)

  Background:
    Given корпус проиндексирован (спеки и код из GitLab, книги из внешнего хранилища)
    And пользователь авторизован через корпоративный SSO (BR-constraint.sso-readonly-access)

  Scenario: Ответ на конкретный вопрос со ссылками на артефакты
    Given пользователь задаёт конкретный вопрос по спецификации или коду
    When система извлекает контекст из графа знаний (retrieval без LLM, PPR/PathRAG)
    Then система возвращает ответ со ссылками на артефакты (grounding, provenance)
    And каждая ссылка ведёт на реально существующий артефакт/чанк (валидация до выдачи)
    And каждый факт трассируется до документа или чанка (K1)

  Scenario: Нет релевантных источников — честный отказ
    Given вопрос не имеет релевантных источников в корпусе
    When система выполняет поиск
    Then система возвращает честный отказ с объяснением, а не галлюцинацию

  Scenario: Двусмысленный запрос — уточняющий вопрос
    Given запрос допускает несколько трактовок
    When система распознаёт двусмысленность
    Then система задаёт уточняющий вопрос вместо ответа

  Scenario: Противоречивые источники
    Given в корпусе есть противоречивые утверждения об одной сущности
    When система формирует ответ
    Then система перечисляет оба варианта с происхождением (полный контур конфликт-детекции — Фаза 2)

  Scenario: Доступность ответа для screen reader (a11y)
    Given пользователь использует screen reader (NVDA / VoiceOver)
    When ответ отображается в веб-интерфейсе
    Then ответ, ссылки на источники и статусы имеют текстовые альтернативы (WCAG 2.1 AA)
    And навигация достижима с клавиатуры (keyboard-only)
```
