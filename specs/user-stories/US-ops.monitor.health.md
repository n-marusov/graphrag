# US-ops.monitor.health — Наблюдение за состоянием контура

```gherkin
@US-ops.monitor.health @P2 @ops
Feature: US-ops.monitor.health Администратор наблюдает состояние контура знаний (золотые сигналы)

  Background:
    Given администратор авторизован через корпоративный SSO (BR-constraint.sso-readonly-access)
    And контур развёрнут (Docker Compose)

  Scenario: Просмотр статусов и метрик
    Given администратор открывает панель мониторинга
    When система публикует золотые сигналы (REQ-NFR-api.observability.golden-signals)
    Then отображаются статусы индексации, латентность ответа (p50/p95), доля ошибок, насыщенность очередей, число LLM-вызовов, время публикации индекса
    And метрики имеют мягкие пороги (warn): доля ошибок < 1%, насыщенность < 80%, время публикации ≤ 15 мин (p95)

  Scenario: Событие безопасности контура LLM
    Given фильтрация утечек зафиксировала событие (SecurityEventEmitted)
    When ИБ открывает панель аудита
    Then событие отображается: пользователь/агент, действие, время, результат
```
