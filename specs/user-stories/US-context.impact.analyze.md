# US-context.impact.analyze — Анализ влияния изменения артефакта

```gherkin
@US-context.impact.analyze @UC-context.impact.analyze @P0 @context
Feature: US-context.impact.analyze Изменение артефакта разворачивается в детерминированный список связанных артефактов (F3.1, K4)

  Background:
    Given граф связей артефактов построен и актуален (F2)

  Scenario: Детерминированный список затронутых артефактов
    Given пользователь (разработчик/архитектор) изменяет артефакт (спека, код, ADR)
    When система вычисляет влияние по рёбрам графа связей (без LLM)
    Then система возвращает детерминированный список связанных артефактов с типами и направлениями связей (InfluenceComputed)
    And повторный прогон анализа даёт тот же список затронутых

  Scenario: Артефакт не найден в графе
    Given артефакт отсутствует в графе знаний
    When пользователь запрашивает анализ влияния
    Then система сообщает, что артефакт не найден, и предлагает инициировать индексацию (F2)

  Scenario: Циклы зависимостей
    Given в графе есть циклы зависимостей
    When система выполняет анализ влияния
    Then система детектирует и дедуплицирует циклы без зацикливания

  Scenario: Неполный граф связей
    Given связи артефакта неполные
    When система выполняет анализ влияния
    Then результат помечается «связи неполны» (без ложной полноты)
```
