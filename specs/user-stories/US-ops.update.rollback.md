# US-ops.update.rollback — Обновление контура и откат

```gherkin
@US-ops.update.rollback @P2 @ops
Feature: US-ops.update.rollback Администратор обновляет контур и откатывает неудачное обновление

  Background:
    Given администратор авторизован через корпоративный SSO (BR-constraint.sso-readonly-access)
    And опубликована новая версия индекса (версионные снапшоты, ADR-IMPL.DATA.incremental-update-snapshot-publish)

  Scenario: Откат к предыдущему опубликованному снапшоту
    Given обновление/публикация новой версии завершилась с ошибкой
    When администратор выполняет откат
    Then система переключает активную версию на предыдущий опубликованный снапшот без перестройки (REQ-NFR-data.maintainability.versioned-provenance)
    And запросы обслуживаются из последней опубликованной версии (без «полусобранного» состояния)

  Scenario: Неудачное обновление — атомарная публикация защищает состояние
    Given во время сборки новой версии произошёл сбой
    When система завершает обработку
    Then частично собранное состояние никогда не становится активным
    And выполняющиеся запросы продолжают работать на старой версии
```
