## Описание

Корпус знаний потребляет онтологию предметной области целевого проекта в формате `.ttl` (OWL 2, Turtle) из GitLab (репозиторий модели; тип T3 перечня). Обработка в F2: парсинг OWL → валидация → проекция T-box в граф (классы → labels, object properties → relationship types, иерархия) — детерминированно, без LLM. Потреблённая онтология типизирует сущности графа знаний и связи графа артефактов (mutual indexing, KAG). Канон онтологии — `*.ttl` в репозитории модели; экспорт онтологии системой не предусмотрен (GraphRAG не источник правды).

## Критерии приёмки

- `.ttl`-файл онтологии из репозитория модели парсится как валидный OWL-Turtle; невалидный — пропуск с WARN
- Проекция T-box строится без обращений к LLM (детерминированный контур F2)
- Сущности графа знаний и артефакты типизируются классами/свойствами потреблённой онтологии; термины ответов соответствуют глоссарию/онтологии (G3, REQ-NFR-data.maintainability.ontology-model)
- Файлы форматов вне перечня T1–T5 пропускаются с WARN и в корпус не включаются (A3, UC-knowledge.sync.gitlab-index)
