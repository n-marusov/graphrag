## Описание

Корпус знаний потребляет структурированные данные в форматах JSON и YAML из GitLab (конфигурации, OpenAPI, CI, docker-compose и др.; тип T5 перечня). Природа описываемого объекта не влияет на обработку: конвейер един для всех JSON/YAML-файлов. Обработка в F2: парсинг структуры (ключи, вложенность, массивы) → проекция в граф (узлы и связи) — детерминированно, без LLM; LLM — опционально (обогащение описаний).

## Критерии приёмки

- JSON/YAML-файлы из GitLab парсятся структурно; ключи, вложенность и массивы отражаются в графе (узлы/связи) с привязкой к артефакту
- Природа объекта (OpenAPI/CI/docker-compose/конфиг) не изменяет конвейер обработки
- Файлы форматов вне перечня T1–T5 пропускаются с WARN и в корпус не включаются (A3, UC-knowledge.sync.gitlab-index)
