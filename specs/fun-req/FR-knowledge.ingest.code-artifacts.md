## Описание

Корпус знаний потребляет исходный код приложений целевого проекта из GitLab — на любом языке стека целевого проекта (Go, TypeScript и др.; тип T2 перечня). «Go-only» — ограничение реализации самой GraphRAG, не корпуса. Обработка в F2: структурный разбор по языку (AST) → извлечение модулей, функций, типов и связей → LLM-обогащение и установление связей «требование → реализация».

## Критерии приёмки

- Исходные файлы стека целевого проекта (по расширениям/детектору языка) индексируются структурно: модули, функции, типы и их связи попадают в граф с привязкой к чанкам
- Связь «требование → реализация» устанавливается между артефактами спек и кода (F3.1, граф зависимостей артефактов)
- Файлы форматов вне перечня T1–T5 пропускаются с WARN и в корпус не включаются (A3, UC-knowledge.sync.gitlab-index)
