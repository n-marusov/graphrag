## Формулировка правила

Шапка веб-интерфейса содержит: слева — название продукта; справа — **версию индекса**, **переключатель темы** (тёмная/светлая; по умолчанию — тёмная) и **выбор языка выпадающим списком** (русский/английский). Выбор темы и языка сохраняется на время сессии пользователя.

## Обоснование

Версия индекса — часть provenance ответа (`REQ-NFR-data.maintainability.versioned-provenance`), видима пользователю для воспроизводимости. Темы — тёмная/светлая (`ADR-DES.UI.tailwind-css-adoption`, «тёмная тема по умолчанию»). Локализация ru/en — `BR-constraint.web-app-browser-chat`; формат выбора (выпадающий список) — решение дизайн-сессии.

## Критерии проверки

- Переключатель темы меняет палитру всех экранов (токены `@theme`)
- Выбор языка — выпадающий список «RU / EN», без жёстко зашитых строк (i18n)
- Версия индекса в шапке соответствует версии, из которой построен текущий ответ
- Переключатели доступны с клавиатуры (WCAG 2.1 AA)
