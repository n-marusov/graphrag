## Формулировка правила

Бэкенд GraphRAG предоставляет **CLI для выполнения запросов** к системе знаний: отправка запросов и получение ответов из терминала — в том числе для тестирования и автоматизации. CLI **не является инструментом администрирования** системы.

**Разграничение CLI (уточнение 2026-08-30, open-questions.md Q2.7/Q2.8):** CLI продукта (запросы к системе знаний) не предоставляет административных функций. Вывод из эксплуатации и управление стеком выполняются **инфраструктурными CLI-инструментами** (Docker Compose down / `docker volume rm`) — это не функции CLI продукта (см. `US-decommission.*`).

## Обоснование

CLI — допустимый канал прецедентов использования (vision.md §2.2: GUI | API | CLI | MCP | Webhook | Schedule). Необходим для прогона тестовых запросов (qa/ §7: golden-наборы «запрос → эталонный ответ → источники» на эмуляторе LLM) и скриптовой автоматизации без графического интерфейса. Административные функции (индексация, статусы, перестройка) в MVP через CLI не предоставляются.

## Критерии проверки

- CLI-команда выполняет запрос к системе знаний и возвращает ответ со ссылками на артефакты
- CLI пригоден для прогона тестовых запросов (golden-наборы, эмуляция LLM)
- В MVP CLI не предоставляет административных функций (индексация, статусы, перестройка графа)
