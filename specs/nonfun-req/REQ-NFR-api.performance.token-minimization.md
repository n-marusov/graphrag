## Описание

Минимизация токенов и числа LLM-вызовов как сквозное требование: локальные GPU и open-weight модели с ограниченным контекстом; экономия токенов — через онтологический слой, PathRAG, PPR (без LLM на этапе извлечения).

## Критерии приёмки

- Полнота контекста при минимуме токенов на эталонных задачах (F3, vision §2.5): доля артефактов, необходимых для задачи, включённых в контекст, при минимальном размере контекста в токенах — **≥ 90%** (доля необходимых артефактов в контексте; целевое значение стейкхолдера 2026-08-30, подтверждается замером исходного уровня, vision §1.4)
- Размер контекста на интерактивный запрос (эталонный набор): **медиана ≤ 4 000 токенов, p90 ≤ 8 000**
- Число LLM-вызовов на запрос: **≤ 2** (медиана), абсолютный лимит **≤ 3** (retrieval без LLM — PPR/PathRAG)
