## Описание

Минимизация токенов и числа LLM-вызовов как сквозное требование: локальные GPU и open-weight модели с ограниченным контекстом; экономия токенов — через онтологический слой, PathRAG, PPR (без LLM на этапе извлечения).

## Критерии приёмки

- Полнота контекста при минимуме токенов на эталонных задачах (F3, vision §2.5): доля артефактов, необходимых для задачи, включённых в контекст, при минимальном размере контекста в токенах
- Целевые значения (размер контекста в токенах на задачу, порог полноты) — TBD: замер на эталонном наборе после замера исходного уровня (vision §1.4; открытый вопрос Q2.2 в open-questions.md)
