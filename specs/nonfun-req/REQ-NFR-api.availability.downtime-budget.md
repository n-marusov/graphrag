## Описание

Система — производная вспомогательная (индекс поверх источника правды), не критичная: допустимый простой — **15 минут в день суммарно на инстанс** (planned + unplanned). Исходные артефакты не хранятся в системе (источник правды — GitLab/S3, вне системы) → RPO для исходников равен 0. Индекс — производный, не самоценность: восстанавливается полной перестройкой (фоновая), отдельные RPO-гарантии на индекс не устанавливаются.

## Критерии приёмки

- Бюджет простоя: ≤ 15 мин/день суммарно на инстанс (плановые и внеплановые окна); «система не критичная» — без строгого SLA на месячную доступность
- RPO: 0 для исходных артефактов (они в GitLab/S3, система — индекс и контекст, vision §2.7 п.1); потери состояния индекса допустимы — восстановление полной перестройкой
- RTO: восстановление обслуживания запросов ≤ 15 мин на инцидент (в рамках дневного бюджета); при наличии опубликованного снапшота — откат к предыдущей версии без перестройки (`REQ-NFR-data.maintainability.versioned-provenance`)
- Восстанавливаемость подтверждается автотестом: restore-тест в CI — развёртывание из бэкапа (dump Neo4j) → прогон эталонных кейсов K1/K4/K5/K17; периодичность — ежеквартально (целевое; предложение владельца — подтверждается на Фазе 1.5)
- Откат неудачного обновления проверяется тестами (negative-сценарии обновления, версионные снапшоты)
