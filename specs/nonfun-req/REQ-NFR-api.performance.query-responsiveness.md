## Описание

Отзывчивость запросов при фоновой переиндексации: инкрементальные обновления, полные перестройки и фоновые пересчёты не блокируют и не деградируют путь интерактивных запросов. Запросы обслуживаются из последней опубликованной (стабильной) версии индекса без ожидания завершения перестройки.

## Критерии приёмки

- Медиана и p90 времени ответа (G1) при активной фоновой переиндексации не деградируют относительно простоя сверх допустимого порога — `TBD` (фиксируется после замера исходного уровня, vision §1.4 G1)
- Во время переиндексации запросы обслуживаются из последней опубликованной версии индекса, без ожидания завершения перестройки
- Ни один запрос не наблюдает «полусобранное» состояние индекса (атомарная публикация)
- Запросы пользователя имеют приоритет над фоновыми задачами переиндексации
