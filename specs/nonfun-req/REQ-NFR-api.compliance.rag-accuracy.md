## Описание

Точность ответов: порог продолжения внедрения — точность RAG не ниже 70% на утверждённом benchmark-наборе (инструмент оценки — RAGAS; LLM-as-judge).

**Benchmark-набор (утверждён 2026-08-30):** эталонные кейсы K1, K4, K5, K17 + golden-наборы «запрос → эталонный ответ → источники» (qa/, §8). Валидация ссылок: каждая ссылка в ответе — реальный URL на артефакт GitLab/S3 (детерминированная проверка существования, UC-answers.grounding.cited-answer).

## Критерии приёмки

- Точность ответов RAG ≥ 70% на утверждённом benchmark-наборе (RAGAS: faithfulness, answer relevancy; LLM-as-judge; прогон на эмуляторе LLM — qa/ §7; гейт `FG-RAG-EVAL` в CI)
- Ответы подтверждаются источниками (grounding): каждое утверждение трассируется до артефакта; каждая ссылка ведёт на реально существующий артефакт/чанк (валидация до выдачи)
- Target-набор утверждён владельцем продукта до замера (vision §1.4)
