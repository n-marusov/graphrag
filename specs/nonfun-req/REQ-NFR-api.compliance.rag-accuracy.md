## Описание

Точность ответов: порог продолжения внедрения — точность RAG не ниже 70% на утверждённом benchmark-наборе (LLM-as-judge).

## Критерии приёмки

- Точность ответов RAG ≥ 70% на утверждённом benchmark-наборе «запрос → эталонный ответ → источники» (LLM-as-judge, прогон на эмуляторе LLM — qa/ §7)
- Ответы подтверждаются источниками (grounding): каждое утверждение трассируется до артефакта
- Target-набор утверждён владельцем продукта до замера (vision §1.4)
