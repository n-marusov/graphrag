## Описание

Точность ответов: порог продолжения внедрения — точность RAG не ниже 70% на утверждённом benchmark-наборе (инструмент оценки — RAGAS; LLM-as-judge).

Единый порог — нижняя граница (усреднение по набору), но он не должен маскировать разницу между классами запросов: по опыту открытых бенчмарков GraphRAG-систем точность значимо зависит от типа вопроса и набора данных (многошаговое извлечение Recall@5 87.8% vs 73.4% у наивного RAG; F1 на многошаговых вопросах 70.3% vs 67.0%; Precision@10 84.7% vs 61.2% у vector-only; success rate на сложных вопросах ~65% vs ~29%; F1 в специализированном домене 78.0%; точность в структурированном CRM-сценарии 96.7% vs 71.1% у BasicRAG; на простых single-hop вопросах GraphRAG и классический RAG сравнимы — F1 64.8 vs 63.0). Поэтому оценка проводится стратифицированно по классам запросов (сводка бенчмарков — [08-accuracy-benchmarks.md](../../.ai-factory/references/graphrag/08-accuracy-benchmarks.md)).

**Классы запросов (доменная таксономия, `glossary.md`):**
- **Локальный (single-hop, фактологический)** — «глобальный и локальный запрос»: ответ по изолированным чанкам; классический RAG здесь сравним.
- **Многошаговый (multi-hop)** — «многошаговое рассуждение»: связывание фактов из разных артефактов; профильный класс GraphRAG.
- **Глобальный (sensemaking)** — «глобальный запрос»: темы, тренды, связи по всему корпусу (community summaries, PathRAG); преимущество по полноте и разнообразию в 62–83% случаев vs классический RAG.

**Benchmark-набор (утверждён 2026-08-30):** эталонные кейсы K1, K4, K5, K17 + golden-наборы «запрос → эталонный ответ → источники» (qa/, §8), размеченные по классам запросов. Валидация ссылок: каждая ссылка в ответе — реальный URL на артефакт GitLab/S3 (детерминированная проверка существования, UC-answers.grounding.cited-answer).

## Критерии приёмки

- Точность ответов RAG ≥ 70% на утверждённом benchmark-наборе (RAGAS: faithfulness, answer relevancy; LLM-as-judge; прогон на эмуляторе LLM — qa/ §7; гейт `FG-RAG-EVAL` в CI). Точность считается **стратифицированно по классам запросов** (локальный / многошаговый / глобальный): публикуется и проверяется по каждому классу отдельно — среднее по набору не скрывает проседание класса.
- **Стратифицированные целевые значения (решение владельца продукта 2026-08-30):** локальный (single-hop) F1 ≥ 65%; многошаговый (multi-hop) F1 ≥ 70% и retrieval Recall@5 ≥ 80%; глобальный (sensemaking) — полнота/разнообразие ответов выше классического RAG не менее чем в 60% случаев на golden-наборе. Совокупное значение ≥ 70% сохраняется как порог продолжения внедрения. Фактический baseline и размер выборки по каждому классу — замер Фазы 1.5 (vision §1.4).
- Ответы подтверждаются источниками (grounding): каждое утверждение трассируется до артефакта; каждая ссылка ведёт на реально существующий артефакт/чанк (валидация до выдачи).
- Target-набор утверждён владельцем продукта до замера (vision §1.4).
